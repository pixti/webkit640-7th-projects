# webkit640-2025

**Webkit640 7기** (2025년 대학·기업 협력형 SW아카데미 사업, 풀스택 개발자 양성과정)에서 진행한 프로젝트 모음입니다.

> 경북형 SW아카데미 7기: https://www.etnews.com/20251209000053

## 📁 프로젝트

| 폴더 | 구분 | 내용 | 기술 스택 |
|---|---|---|---|
| [`semi-project/`](semi-project/) | 이론교육 과제 | Google Gemini API를 활용한 웹소설 AI 번역기 + 커뮤니티(CRUD) | React, Node.js(Express), MySQL, Gemini API |
| [`taxi-app/`](taxi-app/) | 공통 과제 | 택시 호출 앱 (승객용 `taxi/`, 기사용 `driver/`, 서버 `taxi-server/`) | React Native(TypeScript), Node.js(Express), MySQL, Google Maps, Firebase Cloud Messaging |
| [`computer-app/`](computer-app/) | 개인 프로젝트 | 네이버 API로 부품 정보를 수집하는 컴퓨터 견적 사이트 + 커뮤니티 | React(Vite), Node.js(Express, Sequelize), MySQL, Naver 검색 API |

각 프로젝트의 자세한 설명은 폴더 안의 `README.md`를 참고하세요.
